1. symbol_info.h
We implemented the symbol_info structure with basic name and type fields. Necessary getter and setter functions were added for proper data access. This structure works as the fundamental unit of the symbol table.
2. scope_table.h 
The scope_table has been developed with constructor and destructor functions. A hash function (sum of ASCII values % bucket count) is used for indexing. Symbol insertion works correctly and prevents duplicate entries within the same scope.
3. symbol_table.h
The symbol_table constructor and enter_scope() function are fully implemented. The exit_scope() function removes scopes properly but the print_all_scopes() function is not yet completed and remains as a stub.
4. Lexer 
The lexer is fully implemented. It recognizes all keywords, operators, identifiers, integer literals and floating-point numbers. Whitespace and newline handling are also included.
5. Parser 
All required grammar rules have been implemented. Each rule logs output to a file and the total line count is printed at the end. The parser successfully integrates with the lexer.
6. script.sh
A script.sh file has been prepared to automate compilation using yacc/bison and flex, ensuring smooth build and execution.
